# Property Service API

A Spring Boot microservice for managing property listings.  
Built with **Java 17**, **Spring Boot**, **PostgreSQL**, and **Docker Compose**.

---

## 🚀 Features
- **[CRUD operations](ca://s?q=Spring_Boot_CRUD_API)** for properties
- **[DTOs with validation](ca://s?q=Spring_Boot_DTO_and_Mappers)**
- **[Global exception handling](ca://s?q=Spring_Boot_validation_and_error_handling)**
- **[PostgreSQL persistence](ca://s?q=Spring_Boot_PostgreSQL_integration)**
- **[Dockerized environment](ca://s?q=Dockerize_Spring_Boot_app)**
- **[Postman collection](ca://s?q=Postman_collection_for_testing)** for API testing

---

## 🛠 Prerequisites
- Java 17+
- Maven 3+
- Docker & Docker Compose
- Postman (optional, for API testing)
